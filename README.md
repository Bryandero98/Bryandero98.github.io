## Stack

HTML, CSS y JavaScript sin build step ni dependencias — pensado para
desplegarse tal cual en GitHub Pages.

## Estructura

- `index.html` — contenido y estructura de la página
- `styles.css` — tema oscuro/claro, tipografía, layout responsive
- `script.js` — toggle de tema/idioma, scrollspy, copiar al portapapeles
- `i18n.js` — diccionario ES/EN
- `404.html` — página de error a medida
- `.github/workflows/` — chequeo semanal de enlaces + auditoría Lighthouse
